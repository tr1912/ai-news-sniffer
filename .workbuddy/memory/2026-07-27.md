## 定时推送时间调整 + 通知跳过 bug 修复

### 问题
用户报告：昨晚自动执行的 workflow 成功了，但没有收到推送通知。

### 根因
白天用户手动触发过 workflow（`workflow_dispatch`），完成了 build → publish → notify 全流程，
run 记录状态变为 `NOTIFIED`。晚上定时任务（`schedule`）再次运行同一日期，`run_id` 相同：
1. `save_prepared` 发现 run 已存在，保留 `NOTIFIED` 状态不变
2. `mark-published` 发现已是 PUBLISHED/NOTIFIED，跳过状态变更
3. `notify` 检查 `record.status is NOTIFIED and not args.force` → true（定时任务不带 `--force`）→ skip

### 修复
- `.github/workflows/daily-digest.yml`：notify 步骤始终传 `--force`，不再区分 schedule/workflow_dispatch
- cron 从 `"0 13 * * *"` (UTC 13:00 = 北京 21:00) 改为 `"0 11 * * *"` (UTC 11:00 = 北京 19:00)
- 提交：`e2de472`，已推送 origin/main
