## 修复重复跑不渲染、不通知的 bug

根因：`save_prepared` 发现 run_id 已存在时直接返回旧记录，不重写报告 JSON，
导致 `load_reports()` 读到旧数据 → 渲染出相同站点。`notify` CLI 在状态已是
NOTIFIED 时静默返回 0。

修复：
- state.py: save_prepared 始终重写报告 JSON，合并新指纹到已有记录
- cli.py notify: 状态 NOTIFIED 时输出 skip 日志到 stderr
- cli.py mark-published: 已发布时也输出 skip 日志
- 提交：3366598

## 修复 GitHub Actions 不存在的 action 版本号

问题：截图显示所有 CI 运行失败。根因是 workflow 用了不存在的 action 版本：
`actions/checkout@v6`、`actions/setup-python@v6`、`actions/upload-artifact@v7`。

影响：CI 卡在 Set up job；Daily AI Digest 和 Source audit 也用了同样错误版本，
会导致定时/手动日报无法执行。

修复：统一改为官方稳定版本
- actions/checkout@v4
- actions/setup-python@v5
- actions/upload-artifact@v4

涉及文件：
- `.github/workflows/ci.yml`
- `.github/workflows/daily-digest.yml`
- `.github/workflows/source-audit.yml`

- 提交：a62897e
- 75/75 tests pass
